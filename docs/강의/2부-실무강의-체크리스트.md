**2026-09-10 (목) · 피크 × 이오딩 · 40~50분 · 한 장이면 됩니다**

오늘 하는 일: 계약서 파일 하나로 → 지시서 만들고 → 로봇이 ERP를 채우고 → **[판매 시작]은 내가 누른다.**
막히면 손 드세요. 막히는 것도 오늘 볼 거리입니다.

| ☐ | **`로그인 상태 유지` 체크** | 로그인 화면에서 이 칸을 꼭 켭니다. 안 켜면 로봇 돌리는 중에 튕깁니다 |

> 그때 조치는 → claude.ai 로그인 확인 → **크롬 완전히 껐다 켜기** → `다시 이어서 해줘`.

## 0단계 · 폴더 하나 만들기 (3분)

바탕화면에 폴더를 만들고 그 안에 **계약서 파일**과 **`사진` 폴더**를 넣습니다.

```
호텔세팅\다낭_샘플리조트\
    계약서.xlsx          ← 룸별·시즌별 1박 요금표가 들어 있어야 합니다
    사진\
        hotel_01.jpg          ← 대표 1장
        hotel_02.jpg …        ← 상세 4~8장
        room_deluxe_01.jpg    ← 룸마다 1~2장
```

**여기서 볼 것** — 사진 이름은 **영문**으로. 한글 이름은 올라가다 실패합니다.
**여기서 흔한 질문** — "계약서가 한글 문서(hwp)인데요?" → 됩니다. xlsx · pdf · docx · hwp 다 읽습니다.
**막히면** — 요금표가 없는 계약서면 여기서 멈춥니다. **가격 단계를 만들 수 없습니다.** 요금표를 받아 오세요.

## 1단계 · Code 에서 폴더 고르기 (2분)

데스크톱 앱 **Code** 를 열고, **첫 메시지를 보내기 전에** 입력창의 **[Project folder]** 로 0단계 폴더를 고릅니다.

**여기서 볼 것** — 입력창 위/아래에 그 폴더 경로가 떠 있어야 합니다.
**여기서 흔한 질문** — "이미 대화를 시작했는데요?" 이럴 땐 폴더를 고르고 **새 대화**로 다시 시작하는 게 빠릅니다.
**막히면** — 폴더를 못 고르겠으면 터미널에서 `cd <폴더>` 하고 `claude`.

## 2단계 · 지시서 만들기 (8~10분 · 도구가 묻는 것에 답합니다)

입력창에 이렇게 씁니다.

> `/stay-setup:stay-setup-guide` 이 폴더의 계약서로 입력 지시서 만들어줘.
> 호텔명 ○○, 도시 ○○, 공급 통화 USD, 거래처 자사, 취소정책은 ○○.

도구가 되묻습니다. **답 세 가지만 준비하면 됩니다.**

| 도구가 묻는 것 | 이렇게 답합니다 |
|---|---|
| 공급 통화 | 기본이 **USD**. 계약서가 현지 통화(VND·JPY)라도 **확인해 주기 전엔 USD** 로 갑니다 |
| 도시 | 한글명 + 공항코드 3자. `다낭(DAD)` 처럼 |
| 취소정책 | 계약서에 없으면 **공용 정책 이름**을 댑니다. `지정 안 함` 으로 두면 뒤에서 🔴 로 막힙니다 |

**여기서 볼 것 — 이 두 줄이 나와야 다음으로 갑니다.**

- 검사 결과가 **`ALL OK`**
- 파일이 생김: `산출물\<호텔>\<호텔>_입력지시서.html`

그리고 `changes.md` 를 **열어 보세요.** 계약서에 없어서 `비움` 으로 둔 칸이 목록으로 있는데, 나중에 여러분이 화면에서 채울 것들입니다.

**여기서 흔한 질문**
- "`_원고` 폴더는 뭐예요?" → 도구의 작업 파일입니다. **열지 않아도 됩니다.** 담당자가 보는 건 `_입력지시서.html` 하나.
- "값을 고치고 싶어요" → 도구에게 고칠 곳을 말하세요. 도구가 원고를 고치고 **지시서를 다시 만들어야** 합니다. 원고만 고치면 로봇이 그 지시서를 거부합니다.

**막히면** — 검사가 `문제 있음` 이면 도구가 단계 번호를 알려 줍니다. **계약서에 없는 값을 지어내지 마세요.** 모르면 `비움` 으로 두고 나중에 ERP 에서 채웁니다.

## 3단계 · 로봇 돌리기 (1분 · 그다음은 기다립니다)

크롬에서 ERP **호텔 목록 화면**을 연 채로 두고, Code 에 씁니다.

> `/stay-setup:stay-setup-run` 방금 만든 지시서를 크롬의 ERP 에 깔아줘.

**여기서 볼 것** — ERP 화면 **오른쪽 위의 진행 띠**.

```
진행 현황           완료 29 / 전체 77
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
지금: 시즌 가격 채우기 — 성수기        13:42
```

지시서 HTML 을 **옆 탭에 열어 두면** 그 체크 표시도 저절로 올라갑니다.

**여기서 흔한 질문**
- "얼마나 걸려요?" → **13~19분.** 사진 18장 포함해서요.
- "다른 일 해도 돼요?" → 다른 **탭**은 봐도 됩니다. **그 ERP 탭은 건드리지 마세요.** PC 가 잠들지 않게 두세요.

**막히면** — 로그인 화면으로 넘어가면 로봇이 멈추고 말하니까, 그 탭에서 **직접** 로그인하세요. 호텔 목록이 뜨면 알아서 이어갑니다. 안 이어가면 `다시 이어서 해줘`.

## 4단계 · 기다리는 동안 볼 것 (10~15분 · 여기가 오늘 강의의 알맹이)

로봇이 도는 동안 ERP 탭을 **보기만** 하면서 네 곳을 짚습니다. 손대지 않습니다.

### ① 시즌 탭 — 겹치면 안 됩니다

표 머리: `시즌` `우선순위` `전개 일수` `구간` `가격 셀` `깔린 값` `점검` `액션`

- 두 시즌이 **하루도 같은 날을 가질 수 없습니다.** 포함도 겹침입니다.
- `우선순위` 는 **표시 순서일 뿐**입니다. 넓은 시즌 `0`, 다음 `10`, 그 다음 `20`.
- `이미 값이 있는 날도 덮기` 는 **언제나 해제.**

### ② 오퍼 탭 → 연령 구간 — 아이 요금의 출발점

버튼 **[연령 구간 추가]** · 목록 표 머리 `코드` `노출명` `연령 범위` `인원수 포함` `요금 기준` `쓰는 부과금` `액션`

| 칸 | 넣는 값 |
|---|---|
| `밴드 코드` | 영대문자·숫자 **2~8자** — `CHD` · `INF` · `TEEN`. **밑줄·한글 안 됩니다** |
| `노출명` | 계약서가 부르는 말 그대로 (`소아` · `유아`) |
| `최소 연령 (만 나이)` / `최대 연령 (만 나이)` | 유아 `0`~`4.99`, 소아 `5`~`15.99` — **한 살도 겹치면 안 됩니다** |
| `방 인원수에 포함` | 아이가 룸 최대 인원 안에서 자면 **체크** |
| `요금 기준 유형` | `성인 요금의 %` / `정액` / `타 밴드 요금과 동일` / `무료` |

> 구간을 안 만들면 고객 화면 인원 선택기에 **성인만** 섭니다.

### ③ 시즌 [가격] 드로어 — 값을 한꺼번에 까는 유일한 자리

시즌 줄의 **[가격]** → `가격 일괄 전개 — <오퍼> · <시즌>` → 맨 아래 **[이 단가로 깔기]**

- `박수별 단가(선택)` → `3:100,5:90` (3박부터 100, 5박부터 90)
- **`아동 추가 금액 — 소아`** → 아이 1박 요금은 **여기 한 곳에만** 적습니다
- `이미 값이 있는 날도 덮기` → **해제**

> ⚠ **가격 캘린더에서 여러 칸을 드래그로 고르는 기능은 없습니다.** 한 칸씩 눌러 모달로 고치거나,
> 위의 **[가격] → [이 단가로 깔기]** 로 시즌 전체를 한 번에 까는 두 가지뿐입니다.

### ④ 가격 셀 이름 — 조합 코드

`A2C1_CHD` = **성인 2명 · 소아 1명(CHD)**
앞의 `A2` 는 성인 수, 뒤는 여러분이 지은 **밴드 코드가 그대로** 실린 것입니다.

## 5단계 · 배너 보기 (2분 · 합격선)

로봇이 끝났다고 하면 ERP **화면 맨 위 배너**를 보세요.

```
🔴 이대로면 못 팝니다 (0)
🟡 채우면 좋음 (0) ▼
```

**둘 다 0 이어야 합격입니다.**

| 나오면 | 뜻 | 조치 |
|---|---|---|
| 🔴 이 1 이상 | 이대로면 **못 팝니다** | 대개 **취소정책 `지정 안 함`**. 오퍼에서 정책을 고릅니다 |
| 🟡 이 1 이상 | 채우면 좋음 | 시즌 날짜 겹침 · 선택 부과금 금액 없음 · 표시명 없음 |

> 배너에 `이건 넘어가기` 버튼이 있지만 **오늘은 누르지 않습니다.** 🟡 0 이 합격선입니다.

그다음 **가격 캘린더와 요금제, 부과금**을 한 번씩 훑습니다.

## 6단계 · [판매 시작] 누르기 + 값 맞춰 보기 (5분)

배너의 **[판매 시작]** 을 **직접** 누릅니다. 로봇은 이 버튼을 절대 누르지 않습니다.
누르면 상태가 `판매중` · `오퍼 N건이 고객 화면에 팔리는 중입니다` 로 바뀝니다.

### 그다음 — 고객 예약 페이지를 열어 금액을 확인합니다

| 고르는 인원 | 아이 나이 | 나와야 하는 금액 |
|---|---|---|
| 성인 2 | — | 기준 금액 |
| 성인 2 · 아동 1 | **만 3세** | 유아 구간 값 — 무료 계약이면 **그대로**, 유료(쉐어베드)면 **+ 유아 추가 금액** |
| 성인 2 · 아동 1 | **만 7세** | 무료 계약이면 **그대로**, 소아가 유료면 기준 금액 **+ 아동 추가 금액** |
| 성인 2 · 아동 1 | **만 17세** | **성인 3명** 값 |

> 오늘 새로 깐 데모 호텔 숫자(USD · LOW SEASON · 디럭스 가든뷰 1박, 원화는 여행사 환율로 환산돼 보임): 성인 2 = **72.29** / +만 3세 = **72.29 + 8.64 = 80.93** / +만 7세 = **72.29 + 17.28 = 89.57** / +만 17세 = 성인 3명 값 **72.29 + 34.57 = 106.86**
> 운영 중인 씨센스(43886)는 유아·소아가 다 무료라 앞의 셋이 전부 **72.29** 입니다.

**마지막은 직원 예약 화면입니다.** 같은 조건을 넣어 **같은 값**이 나오는지 봅니다.
고객 화면과 직원 화면 값이 다르면 그 자리에서 말씀해 주세요.

# 부록 A · 막혔을 때 다섯 가지

### 1. 로그인이 풀렸습니다
로봇이 멈추고 "ERP 탭에서 로그인해 달라" 고 말합니다.
→ **그 탭에서 직접** ID와 비밀번호, 인증앱 6자리를 넣으세요. 호텔 목록이 뜨면 알아서 이어갑니다.
→ **비밀번호·인증 숫자를 채팅에 적지 마세요.** 적어도 도구는 넣지 않습니다.
→ 예방: 로그인 화면의 **`로그인 상태 유지` 체크**. PC 앞을 비울 거면 크롬 원격 데스크톱을 미리 켜 두세요.

### 2. 확인창(모달)이 떠서 멈췄습니다
→ 화면을 보고 **무엇을 묻는 창인지 읽으세요.** 로봇에게 "그 창 확인 눌러 줘" 가 아니라, 여러분이 판단해서 누릅니다.
→ 이어서 `다시 이어서 해줘`.

### 3. 나이를 안 골라서 예약이 막힙니다
→ 고객 화면에서 아이를 넣었는데 나이 선택이 없거나 금액이 안 바뀌면, **연령 구간이 없는 것**입니다.
→ 오퍼 탭 → **[연령 구간 추가]** 로 유아·소아를 먼저 만듭니다. 부과금의 `연령별 단가` 도 **구간이 있어야** 칸이 생깁니다.

### 4. 검사 도장이 없습니다
> `지시서에 검사 도장이 없다` · `검사기를 통과하지 못한 지시서다` · `원고가 지시서보다 새롭다`

→ 셋 다 **지시서를 다시 만들면** 풀립니다. 2단계로 돌아가서 `ALL OK` 를 받으세요.
→ **우회하지 마세요.** 도장은 틀린 값으로 ERP 를 반쯤 채우는 걸 막는 장치입니다.

### 5. 사진이 안 올라갑니다
→ 사진이 **`사진` 폴더**에 있는지, 이름이 지시서와 **같은지** 확인.
→ **10MB 넘는 사진은 줄입니다.** 한 번에 10MB 까지입니다.
→ 사진이 없는 단계는 건너뛰고 로그에 남습니다. **나중에 손으로 올려도 됩니다.**

# 부록 B · 대본 없이 답하는 문장 다섯 개

질문이 나왔는데 답이 준비 안 됐을 때, 그냥 이렇게 말하면 됩니다.

1. **"그건 계약서에 값이 없어서 비워 둔 칸입니다. `changes.md` 에 목록으로 있고, 화면에서 나중에 채우시면 됩니다."**
   값이 왜 비었냐는 질문에 전부 통하는 답입니다.

2. **"도구는 금액을 환산하지 않습니다. 계약서 숫자 그대로 들어갑니다."**
   — 통화·할인율·퍼센트 질문에 씁니다.

3. **"그 버튼은 사람이 누릅니다. 로봇은 [판매 시작]을 절대 누르지 않습니다."**
   "다 자동이면 잘못 팔리는 거 아니냐" 는 걱정에 이렇게 답합니다.

4. **"화면이 바뀌면 도구도 새 판이 나옵니다. 자동 업데이트를 켜 두시면 저절로 받습니다."**
