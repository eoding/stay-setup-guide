# Stay 세팅 도구 설명서 — 2026-09-09 배포 후 판

## 이 설명서가 답하는 것

계약서 한 장을 ERP Stay 상품으로 옮기는 도구를 쓰는 법이다. 지시서를 만드는 스킬(stay-setup-guide), 지시서를 크롬에서 실행하는 스킬(stay-setup-run), 지시서를 API 로 직접 설치하는 MCP(stay-installer-mcp). 9월 9일 운영 배포로 바뀐 규칙도 여기 있다.

| 도구 | 어디에 | 어떻게 |
|---|---|---|

| MCP 설치기 | 로컬 파이썬 | `stay-installer-mcp` 저장소, `uv venv --python 3.12` → `uv pip install -e .` → `.env` 에 ERP 주소·계정(README) |

## 2. 세 단계

1. **지시서 만들기** — 계약서(PDF·시트)를 폴더에 두고 `/stay-setup:stay-setup-guide` 를 부른다. 도구가 묻는 것(통화·취소정책·모르는 값)에 답하면 `_원고/manual.md` → 검사 → `<호텔>_입력지시서.html`(검사 도장) → `changes.md` 가 나온다. 도장이 `check=ok` 가 아니면 러너가 거부한다.
2. **까는 두 길** — (가) 크롬에서 러너: ERP 에 로그인해 둔 탭을 두고 `/stay-setup:stay-setup-run 지시서를 크롬의 ERP 에 깔아줘`. 화면 오른쪽 위 진행 띠가 오른다. (나) MCP: `python -m stay_installer --yes install <manual.md> --photos <사진 폴더>`. 둘 다 [판매 시작] 은 누르지 않는다.
3. **끝** — 검증 배너 🔴 0 · 🟡 0 을 사람이 확인하고 [판매 시작]. 고객 예약 페이지에서 금액을 한 번 맞춘다.

## 4. 지시서에 새로 생긴 줄

| 줄 | 어디 | 형식 | 뜻 |
|---|---|---|---|
| `인원 조합(선택)` | 시즌 가격 채우기 | `A2,A3` | 정원별 좌표. 숫자로 적어도 `A2` 로 저장 |
| `인원 조합별 조정(선택)` | 시즌 가격 채우기 | `A3:+34.57` | 부호 필수 |
| `박수별 단가(선택)` | 시즌 가격 채우기 | `3:100,5:90` | "3박부터 1박 100". 2~30박, 6층, `1:` 금지 |
| `아동 추가 금액 — <노출명>` | 시즌 가격 채우기 | `8.64` | 유료 구간마다 한 줄. 무료 구간은 줄 없음, % 구간은 자동 |
| `박수~` | 가격 셀 단계 | `3` | 그 박수 이상이면 이 1박 단가 |
| `인원 조합` | 가격 셀 만들기 / 손으로 고치기 | `선택: A2 · 성인 2` / `A2` | 만들기는 셀렉트 글자, 고치기는 키만 |

## 5. 검사기가 새로 잡는 것

검사기(`check_manual.py`, 테스트 415)가 9월 9일 규칙으로 새로 잡는 것이다. 오류는 지시서를 막고, 경고는 남긴다.

- 좌표 키 32자 초과, 코드 없는 `A2C1`, 혼합 철자 `A2C1_C1_CHD`, 밴드 코드 형식(`C`+숫자 포함). 카드 줄의 좌표도 같은 문을 지난다.
- 유료 구간인데 `아동 추가 금액` 이 비었거나 줄이 없다. 무료 구간에 줄이 있다. `성인 요금의 %` 구간에 금액을 적었다. 채우기 회차마다 본다.
- `인원 조합별 조정` 에 부호가 없다, 인원 조합에 없는 키다, 같은 키가 둘이다, 인원 조합이 빈 채로 조정만 있다.
- `박수별 단가` 가 2~30박·6층을 벗어난다, `1:` 을 적었다, 1박 층(`판매 단가`)이 없다. 가격 셀 단계의 `박수~` 가 1~30 을 벗어난다.
- 채우기 회차의 `카드:` 줄이 시즌 이름이 아니라 오퍼를 못 읽는다(경고). 그 회차는 아동 금액·좌표 검사에서 빠진다.
- 그 룸에서 시즌 채우기가 실제로 깐 좌표와 가격 셀 단계의 좌표가 다르다. 카드 줄과 `인원 조합` 칸이 다른 키를 부른다.

## 6. 러너·MCP 가 새로 아는 것

**러너(stay-setup-run 0.9.0)** — 셀 편집 창의 좌표별 묶음 표를 열 번호로 읽는다. 층 둘째 행의 결함을 고쳤다. `박수~`·판매가·정가가 한 칸씩 밀려 저장되던 것이다. 저장 거부 배너(「같은 인원 조합의 가격 행이 이미 있습니다」, 「판매 가능한 셀은 0원일 수 없습니다」, 「박수는 30 이하여야 합니다」)를 읽어 그 단계를 거부로 알린다. 숨은 좌표를 되읽고, 단계에 `박수~` 가 있으면 그 층을 찾는다. 화면 안 확인창은 `[data-stay-confirm="ok"]` 를 대신 누른다. 파서 게이트가 박수 30·층 6·밴드 코드·좌표 32자를 파일 단계에서 막는다.

**MCP 설치기(stay-installer-mcp, 테스트 43)** — 사전 점검이 ERP 의 파서를 그대로 불러 좌표 키 32자, 코드 없는 `A2C1`, 조정 부호, 박수별 단가 2~30박·6층을 화면과 같은 문구로 막는다. 유료 정액 구간인데 아동 추가 금액이 빈 채우기는 시작 전에 막는다. 설치 뒤 되읽기(`cell_check`)가 좌표 전부 A-형인지, 아동 조합 셀이 성인 좌표 + 아동 금액인지, 박수 층이 날짜마다 고른지, 32자 초과가 없는지 본다. ERP 의 견적 경고(`CHILD_AGE_WITHOUT_BAND` 등)는 결과 JSON 에 그대로 실린다. 연령 구간 폼의 새 라벨 `최소 연령 (만 나이)` 도 읽는다.

## 8. 막혔을 때

- 로그인 화면이 뜨면 러너가 멈추고 말하니 그 탭에서 직접 로그인한다. 인증 번호는 도구가 대신 넣지 않는다.
- 검사 도장이 없다: 원고를 한 글자라도 고쳤으면 다시 렌더한다.
- "같은 인원 조합의 가격 행이 이미 있습니다": 그 날짜는 시즌 채우기가 이미 깐 것이다. 새 행을 만들지 말고 위 표의 행을 고친다.
- 밴드 코드 거부: 영대문자·숫자 2~8자. 밑줄·한글은 안 된다.
- 견적이 판매 불가로 나온다: 유료 구간인데 `아동 추가 금액` 을 비웠거나, 요청 박수 이하 박수 층이 없는 날이 끼어 있다.
