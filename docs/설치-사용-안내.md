# 호텔 세팅 스킬 — 설치·사용 안내 (윈도우 · 맥, 1장)

계약서 파일 하나로 ERP Stay 에 호텔을 까는 도구입니다. 두 단계로 씁니다.
① 계약서 → **입력 지시서(HTML)** 만들기 ② 그 지시서를 **Chrome 의 ERP 화면에 자동 입력**하기.
[판매 시작] 은 사람이 누릅니다. 도구는 절대 누르지 않습니다.

**어느 도구로?** 지시서 만들기·손 입력은 **Claude(데스크톱 앱의 Code)** 또는 **Codex(ChatGPT)** 로, 자동 입력은 지금은 **Claude** 로 합니다. Codex 자동 입력(Codex Chrome 확장 + 개발자 모드)은 실측 뒤 확정합니다.

---

## 1. 한 번만 하는 설치 (약 20분)

| 순서 | 할 일 | 방법 |
|---|---|---|
| 1 | **Google Chrome** | 이미 있으면 통과. 없으면 google.com/chrome 에서 설치 |
| 2 | **Claude 계정 로그인** | Chrome 에서 claude.ai 접속 → 회사에서 받은 계정으로 로그인 (Pro·Max·Team 요금제 필요, 무료 계정은 안 됩니다) |
| 3 | **Claude in Chrome 확장** | Chrome 에서 claude.ai/chrome 접속 → [Chrome 에 추가] → 확장 아이콘을 눌러 같은 계정으로 로그인. 설치 뒤 Chrome 을 한 번 완전히 껐다 켭니다 |
| 4 | **Git for Windows** | git-scm.com/download/win → 설치 (모든 선택은 기본값 그대로 [Next]). 없어도 되지만 있어야 명령 실행이 안정적입니다 |
| 5 | **Claude 데스크톱 앱** | claude.ai/download 에서 받아 설치 → 같은 계정으로 로그인 → 왼쪽의 **Code** 를 엽니다. (터미널이 익숙하면 대신 PowerShell 에 아래 한 줄로 Claude Code 를 깔아도 됩니다) |
| 6 | **Python** | Microsoft Store 에서 `Python 3.12` 검색 → [설치] (Store 판이어야 `python3` 명령이 생깁니다) |
| 7 | **스킬 설치(플러그인)** | 데스크톱 앱 **Code** 입력창에 아래 두 줄을 한 줄씩 넣습니다. 그다음 `/plugin` 을 열어 **Marketplaces** 탭의 `eoding-stay` 에서 **자동 업데이트**를 켭니다 — 이후 스킬이 바뀌면 저절로 최신이 됩니다 |
| 8 | **확인** | 입력창에 `/` 만 치면 뜨는 목록에 `stay-setup:stay-setup-guide`, `stay-setup:stay-setup-run` 두 개가 보여야 합니다 |

7번 명령(입력창에 한 줄씩):

```
/plugin marketplace add eoding/stay-setup-guide
/plugin install stay-setup@eoding-stay
```

5번의 터미널 대안(PowerShell):

```
irm https://claude.ai/install.ps1 | iex
```

**맥이면 (5·6·7번만 다름)**
- 5번: 데스크톱 앱은 같습니다. 터미널 대안은 `curl -fsSL https://claude.ai/install.sh | bash`.
- 6번: 터미널에서 `python3 --version` 을 쳐서 3.10 이상이 나오면 통과. 안 나오면 python.org 에서 macOS 설치판을 받아 설치합니다.
- 7번: 같습니다(플러그인 설치 두 줄은 맥·윈도우 동일).
- 2번 이후 폴더 예시는 `~/호텔세팅/다낭_샘플리조트/` 이고, 데스크톱 앱 Code 에서 [Project folder] 로 고르는 것은 같습니다.

**Codex(ChatGPT)로 쓸 때 (지시서 만들기·손 입력)**
- Codex 앱 또는 터미널 Codex 에서 두 줄: `codex plugin marketplace add eoding/stay-setup-guide` → `codex plugin add stay-setup@eoding-stay`. 새 판은 `codex plugin marketplace upgrade` 로 받습니다.
- Python 3.12 는 위 6번과 같습니다. 자동 입력(Chrome)은 Codex 에서는 아직 실측 전이라 손 입력까지만 안내합니다.

## 2. 호텔 하나 까는 순서 (약 30분 + 자동 입력 15~20분)

**준비물**: 계약서(**룸별·시즌별 1박 요금표가 꼭 들어 있어야 합니다** — 없으면 가격 단계를 못 만듭니다) · 호텔 사진(대표 1장, 상세 4~8장, 룸마다 1~2장) · 취소정책 이름(계약서에 없으면 우리 공용 정책 이름)

1. 폴더를 하나 만듭니다. 예: `C:\호텔세팅\다낭_샘플리조트\`
   그 안에 계약서 파일과 `사진` 폴더를 넣습니다. 사진 이름은 `hotel_01.jpg`, `room_deluxe_01.jpg` 처럼 영문으로.
2. 데스크톱 앱 **Code** 를 열고, 첫 메시지를 보내기 전에 입력창의 **[Project folder]** 로 그 폴더를 고릅니다. (터미널이면 `cd C:\호텔세팅\다낭_샘플리조트` 뒤 `claude`)
3. 이렇게 말합니다.
   > `/stay-setup:stay-setup-guide` 이 폴더의 계약서로 입력 지시서 만들어줘. 호텔명 ○○, 도시 ○○, 공급 통화 USD, 거래처 자사, 취소정책은 ○○.
   묻는 것(통화·도시 코드·취소정책·빈 값)에 답하면 **지시서** `산출물\<호텔>\<호텔>_입력지시서.html` 이 생깁니다. 이 파일 하나가 결과물입니다 — 담당자에게 건네는 것도, 자동 입력이 읽는 것도 이것입니다. 같은 폴더의 `사진` 과 `changes.md`(비워 둔 칸 목록)까지가 볼 것이고, `_원고` 폴더와 나중에 생기는 `<호텔>_실행` 폴더는 **도구의 작업 파일이라 열어 보지 않아도 됩니다**(`_원고\manual.md` 는 지시서를 만든 원고, `<호텔>_실행\steps.json` 은 자동 입력이 쓰는 내부 파일입니다). **검사 결과가 `ALL OK` 인지 확인**합니다. (자동 입력은 검사를 통과한 HTML 지시서만 받습니다 — `문제 있음` 이면 값을 채워 다시 만들어야 합니다.)
   **손으로 깔 때는 여기서 끝입니다.** `<호텔>_입력지시서.html` 을 열어 위에서부터 한 단계씩 따라 치면 됩니다(단계마다 체크 표시·값 복사 버튼이 있고, 마지막 줄이 눌러야 할 버튼입니다). 처음 한두 호텔은 이렇게 손으로 깔아 화면을 익히고, 그다음부터 5번의 자동 입력을 쓰는 것을 권합니다.
4. (자동 입력) Chrome 에서 ERP(주소는 담당자에게 받은 것)에 로그인하고 **호텔 목록 화면을 연 채로** 둡니다. 로그인은 세 화면입니다 — ① ID·비밀번호 → [로그인] ② **다중 인증**: 휴대폰 인증앱(Google Authenticator 등)의 6자리 숫자를 넣고 [인증] (30초마다 바뀌니 보이는 숫자를 바로 넣습니다) ③ 호텔 목록. 도구가 도중에 로그인 화면을 만나면 멈추고 "ERP 탭에서 로그인해 달라" 고 말합니다 — **비밀번호와 인증 숫자는 사람이 그 탭에 직접 넣습니다**(채팅에 숫자를 적어 보내도 도구는 넣지 않습니다). 호텔 목록이 다시 뜨면 도구가 알아서 이어서 갑니다.
5. (자동 입력) Claude Code 에 말합니다.
   > `/stay-setup:stay-setup-run` 방금 만든 지시서를 Chrome 의 ERP 에 깔아줘.
   도구가 호텔을 만들고 오퍼·룸·시즌·가격·사진까지 순서대로 넣습니다. 화면을 건드리지 말고 기다립니다. (PC 가 잠들지 않게 두세요)
   **진행 상황**은 ERP 화면 오른쪽 위의 띠에서 보입니다(`12 / 77 · 지금: 룸 만들기 …`). 지시서 HTML 을 옆 탭에 열어 두면 그 체크도 저절로 올라갑니다.
6. 손으로 깔았든 자동으로 깔았든, 끝나면 ERP 화면 맨 위 배너를 봅니다. **🔴 0 · 🟡 0** 이어야 합니다. 그다음 가격 캘린더·요금제·부과금을 한 번 훑어보고, 맞으면 **[판매 시작]** 을 직접 누릅니다.

## 3. 자주 막히는 곳

| 증상 | 조치 |
|---|---|
| "브라우저 확장이 연결되지 않았습니다" | Chrome 에서 claude.ai 에 로그인돼 있는지, 확장 아이콘이 로그인 상태인지 확인 → Chrome 껐다 켜기 → Claude Code 에 "다시 이어서 해줘" |
| ERP 가 로그인 화면으로 넘어감 | Chrome 의 그 탭에서 ID·비밀번호와 인증앱 6자리를 직접 넣어 로그인합니다. 호텔 목록이 뜨면 도구가 알아서 이어가고, 안 이어가면 "다시 이어서 해줘" |
| 지시서 검사에서 `문제 있음` | 도구가 알려 주는 단계 번호를 보고 값을 알려 줍니다. 계약서에 없는 값을 지어내지 않습니다 — 모르면 `비움` 으로 두고 나중에 ERP 에서 채웁니다 |
| 어느 파일이 지시서인지 헷갈림 | 담당자가 보는 것은 `<호텔>\<호텔>_입력지시서.html` 하나입니다. `_원고` 폴더(원고 `manual.md` 등)와 `<호텔>_실행` 폴더(`steps.json` 등)는 도구가 쓰는 작업 파일이라 건드리지 않습니다 |
| 지시서 내용을 고치고 싶음 | 도구에게 고칠 곳을 말합니다. 도구가 원고를 고친 뒤 지시서를 **다시 만들어야** 합니다 — 원고만 고치면 자동 입력이 그 지시서를 거부합니다 |
| 사진이 안 올라감 | 사진 파일이 `사진` 폴더에 있는지, 이름이 지시서와 같은지 확인. 10MB 넘는 사진은 줄입니다 |
| 통화가 USD 가 아니라고 물어봄 | 계약서 통화가 맞으면 그 통화로 하라고 답합니다. 도구는 금액을 환산하지 않습니다 |
| 이미 같은 이름의 호텔·정책이 있음 | 도구가 건너뜁니다(정상). 로그에 `건너뜀` 으로 남습니다 |

**지키는 것**: 판매 시작은 사람이 · 사진 저작권 확인은 담당자 책임 · ERP 화면이 바뀌면 스킬도 새 판이 나오는데, 7번에서 자동 업데이트를 켜 두었으면 저절로 받고, 아니면 `/plugin update stay-setup@eoding-stay` 한 줄.
