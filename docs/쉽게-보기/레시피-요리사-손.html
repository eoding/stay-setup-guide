호텔 하나를 ERP에 깔 때, 안에서는 이런 일이 일어나요

레시피가 있고, 레시피를 읽는 요리사가 있고, 실제로 냄비를 만지는 손이 있어요. 손님에게 내놓는 건 사장님만 해요.

steps.json

레시피

계약서로 만든 지시서예요. "객실 탭 → 룸 추가 → 이름 '디럭스' → 면적 35 → 저장" 같은 줄이 70~130개. 값은 전부 계약서에서 온 것이고, 없는 값은 안 지어내요.

stay_boot.js

요리사

레시피를 한 줄씩 읽고 "이건 룸 만들기구나" 하고 알아본 뒤 손에게 시켜요. 끝나면 화면 값을 다시 읽어 레시피와 맞는지 대조하고, 옛날 레시피면 시작도 안 하고 멈춰요.

stay_helper.js

손

탭을 열고, "면적(㎡)" 같은 글자로 칸을 찾고, 글자를 치고, 고르고, 사진을 넣고, 저장을 눌러요. ERP 화면 생김새를 아는 건 이 손뿐이라 화면이 바뀌면 손을 고쳐요.

Claude Code + Chrome 확장

주방 문

로그인해 둔 ERP 탭 안으로 요리사와 손을 들여보내요. 큰 파일은 숨은 파일 칸으로 올리고, 한 번에 45초만 움직일 수 있어서 3~10단계씩 끊어서 해요.

사람

사장님

계약서와 사진을 폴더에 넣고, ERP에 로그인하고, 다 깔린 뒤 배너에 🔴 0 · 🟡 0 인지 보고 [판매 시작]을 눌러요. 이 버튼은 로봇이 절대 못 눌러요.

순서로 보면

  1. 1계약서·사진 폴더에 넣기 (사람)
  2. 2지시서 만들기 → 검사 ALL OK
  3. 3Chrome 에서 ERP 로그인 (사람)
  4. 4요리사+손이 70~130단계 자동 입력 (13~19분)
  5. 5배너 🔴 0 · 🟡 0 확인 → [판매 시작] (사람)

주황 테두리가 사람이 하는 일이에요. 지시서 검사를 통과 못 하면 4번은 아예 시작하지 않아요.
