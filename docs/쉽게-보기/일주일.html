호텔 하나를 ERP에 깔던 일, 일주일 만에 로봇 일이 됐어요

9월 3일부터 오늘 아침까지. 계약서를 넣으면 레시피가 나오고, 로봇 손이 ERP를 채우고, 사장님은 [판매 시작]만 누르면 됩니다.

문제

계약서 → 손으로 100칸

호텔 계약서는 수십 장. 직원이 ERP 화면 20개 탭에 룸·시즌·가격·취소정책을 100칸 넘게 손으로 넣었어요. 오래 걸리고, 틀리고, 사람마다 달랐어요.

만든 것 ①

레시피 만드는 스킬

계약서를 넣으면 "객실 탭 → 룸 추가 → 이름 → 면적 → 저장" 같은 줄이 60~130개 적힌 지시서가 나와요. 검사기가 도장(ALL OK)을 찍어야 다음으로 갈 수 있어요. 도장 없으면 로봇은 시작도 안 해요.

만든 것 ②

자동으로 채우는 스킬

크롬 안 ERP 탭에 로봇 손을 들여보내요. 탭 열고, 칸 찾고, 글자 치고, 사진 올리고, 저장. 호텔 하나에 13~19분. 끝나면 화면 값을 다시 읽어 레시피와 맞는지 대조해요.

시험

일곱 번, 또 일곱 번

시험 호텔 7개(A~G)를 깔고, 틀린 걸 고치고, 다시 깔았어요. 운영 ERP에 씨센스·소나가가 경고 0으로 완주했고, 다른 AI(Sonnet)가 문서만 보고 혼자 해도 같은 결과가 나왔어요.

배포

설치 한 줄로 받는 꾸러미

GitHub 플러그인 가게에 올렸어요. Claude Code에서도, Codex에서도 한 줄로 설치돼요. 윈도우·맥 설치 안내와 파트너용 사용 허가서(라이선스)도 같이 넣었어요.

오늘 아침

대표님께 보낼 링크

씨센스·소나가를 판매중으로 바꾸고 호텔 사진을 올려서, 날짜를 찍으면 사진·객실·가격·프로모션이 다 보이는 예약 페이지 링크 6개를 만들었어요. 노보텔까지 세 호텔이 실제로 팔리는 중이에요.

일주일 동안 배워서 규칙이 된 것

전부 실제로 틀려 보고 나서 문서와 검사기에 박아 넣은 것들이에요.

  • 경고(🟡)가 하나라도 있으면 매뉴얼이 잘못된 것
  • 공급 통화는 USD가 기본, 다른 통화는 물어보기
  • 같은 오퍼의 시즌은 하루도 겹치면 안 됨
  • 오퍼마다 취소정책 필수, 없으면 사람에게 묻기
  • 아이 요금은 한 곳에만 — 두 번 받으면 안 됨
  • 갈라디너는 의무 부과금 하나로
  • 판매 기간은 지시서 만든 날부터
  • 룸 이름은 계약서 원어 그대로

사람만 하는 일은 셋뿐이에요: 계약서와 사진을 폴더에 넣기, ERP에 로그인하기, 배너에 🔴 0 · 🟡 0 을 보고 [판매 시작] 누르기. 남은 숙제는 취소 규정이 없는 호텔 4개(C·D·E·F)에 공용 취소정책을 정하는 것과 옛 시험 호텔 정리예요.
