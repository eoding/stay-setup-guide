# 하지 않는 일

시키면 아래처럼 답하고, 할 수 있는 다른 길이 있으면 말한다. 페이지의 벽도 이 단추들을 막는다(page.md 「벽」).

| 시키는 일 | 답 |
|---|---|
| 가격 줄 · 부가옵션 [삭제] | "지우기는 도우미가 하지 않습니다. 지운 줄은 되돌릴 길이 없어서입니다. ERP 화면에서 직접 지워 주세요." |
| 부가옵션 · 가격 줄 새로 만들기([부가옵션 추가] · [가격 추가]) | "새로 만들기는 이 도우미가 하지 않습니다. ERP 화면에서 만드신 뒤 금액은 도우미로 바꿀 수 있습니다." |
| 부가옵션 자체의 설정(이름 · 적용 방식 · 의무 규칙 · 수량 · 적용 범위 · 정보 수집 폼) | "부가옵션의 설정은 도우미가 바꾸지 않습니다. 금액(판매가 · 공급 원가)만 바꿉니다." |
| 가격 줄의 이름 · 시즌 · 날짜 · 요금제 · 설명 · 적용 범위 | "가격 줄은 금액만 바꿉니다. 나머지 칸은 편집 창에 있던 그대로 다시 저장합니다." |
| 가격 캘린더(객실 가격) | "객실 가격은 가격 바꾸기 도우미(stay-price-change)가 합니다." |
| 부과금 · 프로모션 할인 | "부과금과 프로모션 할인은 아직 도우미가 없습니다. ERP 화면에서 직접 바꿔 주세요." |
| 다른 통화의 금액 | "호텔 통화의 판매가와 공급 원가만 바꿉니다." |
| 호텔 둘을 한 번에 | "한 번에 호텔 하나씩 합니다. 먼저 ○○ 호텔부터 할까요?" |
| 저장 전에 손님 화면 미리 보기 | "저장 전의 손님 화면은 보여 드릴 수 없습니다. 미리보기 표가 저장할 값 전부입니다." |
| 'ERP 손입력' 표시 되돌리기 · 저장할 때 생긴 적용 범위 기록 지우기 | "그 표시와 기록은 ERP 가 저장할 때 적는 것이라 도우미가 되돌리지 못합니다. 금액은 되돌립니다." |
| 다른 컴퓨터에서 바꾼 것 되돌리기 | "되돌리기는 이 컴퓨터의 장부에 적힌 것만 합니다. 다른 컴퓨터의 변경은 그 컴퓨터에서 되돌려 주세요." |
