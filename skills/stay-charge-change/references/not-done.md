# 하지 않는 일

시키면 아래처럼 답하고, 할 수 있는 다른 길이 있으면 말한다. 페이지의 벽도 이 단추와 칸들을 막는다(page.md 「벽」).

| 시키는 일 | 답 |
|---|---|
| 부과금 [삭제] | "지우기는 도우미가 하지 않습니다. 지운 부과금은 시간대 요율까지 함께 사라지고 되돌릴 길이 없어서입니다. ERP 화면에서 직접 지워 주세요." |
| 부과금 새로 만들기([부과금 추가]) | "새로 만들기는 이 도우미가 하지 않습니다. ERP 화면에서 만드신 뒤 금액은 도우미로 바꿀 수 있습니다." |
| 부과금의 종류 · 이름 · 부과 방식(정액 ↔ 정률) · 단위(체류당 · 박당 · 인당) · 의무/선택 · 적용 날짜 · 적용 룸 · 설명 · 적용 범위 · 현장 결제 통화 | "부과금의 모양은 도우미가 바꾸지 않습니다. 금액만 바꾸고, 나머지 칸은 편집 창에 있던 그대로 다시 저장합니다. ERP 화면에서 직접 바꿔 주세요." |
| 시간대 줄 더하기 · 지우기 · 시각 바꾸기([요율 행 추가] · 행 [삭제]) | "시간대 줄을 더하거나 지우거나 시각을 바꾸는 일은 도우미가 하지 않습니다. 있는 줄의 금액만 바꿉니다." |
| 연령별 단가 새로 넣기 · 비우기(성인가와 같게) | "연령별 단가 칸을 채우거나 비우는 일은 도우미가 하지 않습니다. 이미 있는 단가의 금액만 바꿉니다." |
| 「미정」 금액 정하기 · 금액을 「미정」으로 · 현장 금액 비우기 | "비어 있는 금액을 채우거나 금액을 비우는 일은 도우미가 하지 않습니다(금액의 뜻이 바뀝니다). 무료는 0 으로 바꿀 수 있습니다." |
| 계산에 쓰이지 않는 칸(정률 부과금의 정액 금액 · 시간대 줄이 있는 부과금의 정액 · 정률) | "그 칸은 이 부과금에서 계산에 쓰이지 않아 바꿔도 손님이 내는 금액이 달라지지 않습니다. 시간대 줄의 금액을 바꿀까요?" |
| [정보 수집 폼] | "정보 수집 폼은 도우미가 만지지 않습니다. ERP 화면에서 직접 고쳐 주세요." |
| 가격 캘린더(객실 가격) | "객실 가격은 가격 바꾸기 도우미(stay-price-change)가 합니다." |
| 부가옵션 금액 | "부가옵션 금액은 부가옵션 가격 도우미(stay-addon-price-change)가 합니다." |
| 새 호텔 세팅 | "새 호텔은 입력 지시서 도우미(stay-setup-guide)로 지시서를 만들고 실행 도우미(stay-setup-run)로 깝니다. 이 도우미는 이미 판매 중인 호텔의 부과금 금액만 바꿉니다." |
| 프로모션 할인 | "프로모션 할인 값은 프로모션 할인 도우미(stay-promotion-change)가 합니다 — 화면에 안 보이는 설정을 지키는 표식이 있는 ERP 에서만 저장합니다." |
| 호텔 둘을 한 번에 | "한 번에 호텔 하나씩 합니다. 먼저 ○○ 호텔부터 할까요?" |
| 저장 전에 손님 화면 미리 보기 | "저장 전의 손님 화면은 보여 드릴 수 없습니다. 미리보기 표가 저장할 값 전부입니다." |
| 시간대 줄 · 연령별 단가의 ERP 번호 되돌리기 · 저장할 때 생긴 적용 범위 기록 지우기 | "그 번호와 기록은 ERP 가 저장할 때 새로 매기는 것이라 도우미가 되돌리지 못합니다. 금액은 되돌립니다." |
| 다른 컴퓨터에서 바꾼 것 되돌리기 | "되돌리기는 이 컴퓨터의 장부에 적힌 것만 합니다. 다른 컴퓨터의 변경은 그 컴퓨터에서 되돌려 주세요." |
