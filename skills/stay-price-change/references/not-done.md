# 하지 않는 것 — 담당자가 이렇게 말하면

SKILL.md 가 이 파일을 여는 때: 담당자가 이 도우미가 하지 않는 일을 시킬 때 — 손님 화면 모양 미리 보기, 호텔 둘을 한 번에, 판매 마감 · 객실 · 요금제 · 취소정책, 부과금 · 프로모션 할인 · 부가옵션, 새로 생긴 칸 지우기, 다른 컴퓨터의 기록, 새 요금표 · 시즌 원판(시즌 채우기는 담당자가 하고 도우미는 그 앞뒤를 한다).

| 담당자가 이렇게 말하면 | 이렇게 답한다 |
|---|---|
| "저장하기 전에 홈페이지에서 어떻게 보이는지 보여줘" | "저장하기 전에 손님 화면 모양으로 보여 드리는 기능은 지금은 없습니다. 칸마다 바뀌기 전 → 뒤를 표로 보여 드리고, 적용한 뒤 다시 읽어 확인합니다." |
| "A 호텔이랑 B 호텔 같이 올려줘" | "한 번에 호텔 하나씩 합니다. A 호텔을 마친 뒤 B 호텔을 하겠습니다." |
| "판매 마감해줘", "객실·요금제·취소정책 바꿔줘" | "이 도우미는 가격 캘린더의 값(판매가 · 정가 · 공급 원가)만 바꿉니다. 그 설정은 ERP 에서 직접 바꿔 주세요." |
| "부가옵션 가격 바꿔줘" | "부가옵션 금액(판매가 · 공급 원가)은 부가옵션 가격 도우미(stay-addon-price-change)가 바꿉니다. 그 도우미로 할까요?" |
| "부과금 바꿔줘" | "부과금 금액은 부과금 도우미(stay-charge-change)가 바꿉니다. 그 도우미로 할까요?" |
| "새 호텔 세팅해줘", "계약서로 입력해줘" | "새 호텔은 입력 지시서 도우미(stay-setup-guide)로 지시서를 만들고 실행 도우미(stay-setup-run)로 깝니다. 이 도우미는 이미 판매 중인 호텔의 가격만 바꿉니다." |
| "프로모션 할인 바꿔줘" | "프로모션 할인 값은 프로모션 할인 도우미(stay-promotion-change)가 합니다 — 화면에 안 보이는 설정을 지키는 표식이 있는 ERP 에서만 저장합니다." |
| "되돌렸는데 새로 생긴 칸도 지워줘" | "가격이 없던 칸에 새로 생긴 값은 되돌려도 지울 수 없습니다. ERP 에 칸을 지우는 길이 없어서입니다." |
| "다른 컴퓨터에서 바꾼 것 되돌려줘", "기록 어디 있어?" | "바꾼 기록은 이 컴퓨터의 '내 문서/어딩 Stay 가격 변경 기록'에만 있습니다. 다른 컴퓨터에서 바꾼 것은 여기서 되돌릴 수 없습니다." |
| "새 요금표로 바꿔줘" | [sheet.md](sheet.md) 대로 두 길을 말하고 고르게 한다. |
| "시즌 원판으로 바꿔줘", "시즌 [가격]을 새 요금으로 다시 채워줘" | "도우미는 시즌을 직접 채우지 않습니다 — ERP 의 시즌 채우기는 미리보기 없이 바로 칸을 덮어서, 누르기 전에 무엇이 바뀔지 정확히 보여 드릴 수 없기 때문입니다. 채우기는 ERP 시즌 화면에서 해 주시면, 채우기 전에 지금 값을 저장해 두었다가 채운 뒤 무엇이 바뀌었는지 칸마다 보여 드리고, 원하시면 되돌립니다." 그리고 [sheet.md](sheet.md) 「(가) 시즌 원판 바꾸기」대로 한다. |
