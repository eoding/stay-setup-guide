# 하지 않는 것 — 담당자가 이렇게 말하면

SKILL.md 가 이 파일을 여는 때: 담당자가 이 도우미가 하지 않는 일을 시킬 때 — 손님 화면 모양 미리 보기, 호텔 둘을 한 번에, 판매 마감 · 객실 · 요금제 · 취소정책, 부과금 · 프로모션 할인 · 부가옵션, 새로 생긴 칸 지우기, 다른 컴퓨터의 기록, 새 요금표 · 시즌 원판.

| 담당자가 이렇게 말하면 | 이렇게 답한다 |
|---|---|
| "저장하기 전에 홈페이지에서 어떻게 보이는지 보여줘" | "저장하기 전에 손님 화면 모양으로 보여 드리는 기능은 지금은 없습니다. 칸마다 바뀌기 전 → 뒤를 표로 보여 드리고, 적용한 뒤 다시 읽어 확인합니다." |
| "A 호텔이랑 B 호텔 같이 올려줘" | "한 번에 호텔 하나씩 합니다. A 호텔을 마친 뒤 B 호텔을 하겠습니다." |
| "판매 마감해줘", "객실·요금제·취소정책 바꿔줘" | "이 도우미는 가격 캘린더의 값(판매가 · 정가 · 공급 원가)만 바꿉니다. 그 설정은 ERP 에서 직접 바꿔 주세요." |
| "부과금(프로모션 할인, 부가옵션 가격) 바꿔줘" | "부과금 · 프로모션 할인 · 부가옵션 금액은 따로 만드는 도우미가 맡을 예정이고 아직 없습니다. 지금은 ERP 에서 직접 바꿔 주세요." |
| "되돌렸는데 새로 생긴 칸도 지워줘" | "가격이 없던 칸에 새로 생긴 값은 되돌려도 지울 수 없습니다. ERP 에 칸을 지우는 길이 없어서입니다." |
| "다른 컴퓨터에서 바꾼 것 되돌려줘", "기록 어디 있어?" | "바꾼 기록은 이 컴퓨터의 '내 문서/어딩 Stay 가격 변경 기록'에만 있습니다. 다른 컴퓨터에서 바꾼 것은 여기서 되돌릴 수 없습니다." |
| "새 요금표로 바꿔줘" | [sheet.md](sheet.md) 대로 두 길을 말하고 고르게 한다. |
| "시즌 원판으로 바꿔줘", "시즌 [가격]을 새 요금으로 다시 채워줘" | "(가) 시즌 원판 바꾸기는 도우미가 아직 못 합니다. ERP 시즌 화면에서 직접 해 주세요. 날짜별 가격만 요금표에 맞추는 것은 할 수 있습니다." |
