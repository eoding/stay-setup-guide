# 페이지 쪽 — 올리기 · 작업 · 답 · 오류

차례: 올리기 · 작업 · 답의 모양 · 오류와 할 일

## 올리기

| 부르는 것 | 답 |
|---|---|
| `scripts/page/stay_price_loader.js` 전체 실행 | `{ok: true, bridge: "stay_price_bridge", label: "stay price file bridge", want: ["stay_helper.js", "stay_boot.js", "stay_price.js"]}`. 파일 칸은 1px · 거의 투명이라 화면에 안 보이지만 접근성 트리에 그 이름으로 있다 |
| (파일 올리기 도구) 그 칸에 세 파일 | 한 번에 셋이든 하나씩이든 모인다. `.min.js` 도 받는다 |
| `await stayPriceLoader.load()` | `{ok, label, helper, price, stored, loaded}`. 세 파일을 도우미 → 부트 → 가격 도우미 차례로 실행하고 `stayPrice…` 키 셋에만 적어 둔다. 러너의 키(`stayHelperSrc`·`stayBoot`·`staySteps`·`stayRunCursor`)는 읽지도 쓰지도 않는다 |
| `stayPriceLoader.again()` | 이동 뒤에 적어 둔 원본을 같은 차례로 다시 실행한다. 원본이 없으면 `적어 둔 원본이 없습니다` |
| `stayPriceLoader.status()` | `{ok, label, helper, price, stored}`. 올라 있는지 볼 때 |

올리면 페이지에 벽이 선다. 작업이 도는 동안에는 그 작업의 허용 목록에 없는 클릭·폼 제출을 막고, 작업 밖에서는 스크립트가 만든 클릭을 막는다(사람이 직접 누른 클릭은 지난다). 같은 탭에서 러너(stay-setup-run)를 돌려야 하면 담당자에게 그 탭을 새로 고쳐 달라고 한다. 새로 고치면 도우미가 내려간다.

## 작업

한 번에 하나씩 `await` 로 부르고, 값은 명령(`read-calls`·`reserved`·`calls`)이 낸 그대로 넣는다. 답의 `ask` 는 넣은 값의 지문이라 값을 바꾸면 명령이 그 답을 거절한다. 작업 하나는 45초 안에 화면이 정리된 뒤 답한다.

| 부르는 것 | 넣는 값 | 하는 일 |
|---|---|---|
| `stayPrice.readPair(v)` | `{offer, room, ratePlan, from, to, weekdays}` | [선택 날짜 가격 수정]을 확인 단계까지 열어 지금 값을 읽고 닫는다. 저장 단추는 허용 목록에 없다. 판매일 없는 날은 읽지 않고 「판매일 없음」으로 알린다 |
| `stayPrice.readReserved(v)` | `{offer, rooms, ratePlans, from, to, weekdays, occupancy, nights}` | [선택 날짜 가격 가감]을 확인 단계까지 열어 「예약이 있는 날」을 읽고 닫는다. [가감 적용]은 누르지 않는다 |
| `stayPrice.applyBulk(v)` | `{no, offer, room, ratePlan, dates, rows}` | [선택 날짜 가격 수정] 저장 한 번. 저장 단추는 그 요금제 · 그 날짜로 연 창일 때 한 번만 눌린다 |
| `stayPrice.applyCell(v)` | `{no, offer, room, ratePlan, date, occupancy, nights, clear}` | 날짜 칸을 눌러 여는 셀 창 저장 한 번(정가 · 공급 원가 비우기). 연 창의 날짜 · 요금제 · 줄이 맞을 때만 |
| `stayPrice.take(id, at, size)` | 조각 id, 자리(0 부터), 크기(200~800, 기본 800) | 읽은 조각의 한 쪽. 페이지는 마지막 40개 조각만 둔다 |
| `stayPrice.last()` | 없음 | 마지막 작업의 답. 아직 돌고 있으면 `{running: {op, no, at}}` |
| `stayPrice.idle()` | 없음 | 작업 밖 벽의 상태 `{idle, blocked, count}` |

`standDown()`·`standUp()`·`config()`·`guard()` 는 시험용이다. 이 도우미는 부르지 않는다.

## 답의 모양

작업의 답(JSON 으로 800자 안):

| 칸 | 뜻 |
|---|---|
| `op` · `no` · `ok` | 작업 이름 · 저장 번호(저장 작업만) · 됐는지 |
| `ask` | 넣은 값의 지문. 명령이 물음과 짝짓는다 |
| `saved` | 저장 작업만. `true` 저장됨 · `false` 저장 안 됨 · `"unknown"` 단추는 눌렸고 저장됐는지 모름 |
| `pressed` · `refused` | 저장 단추를 눌렀는지 · 누르기 전에 스스로 거절했는지 |
| `body` | 읽기 작업만. `{id, chars, bytes, crc32, pieces}`. 조각은 `take` 로 받는다 |
| `rest` · `warn` | 답할 때 화면(드로어 · 셀 창 · 요청)이 정리됐는지. `false` 면 다음 작업 전에 기다린다 |
| `what` · `days` · `note` | 무엇을 했는지 · 읽은 날 수(`asked`·`open`·`noSale`) · 메모 |
| `error` · `errors` | 까닭(200자 안) · 화면이 보인 오류 줄 |
| `clicks` · `blocked` · `blockedMore` | 누른 것 수 · 막은 클릭(처음 둘) · 더 막은 수 |
| `cut` | 800자를 넘어 꼭 필요한 칸만 남긴 답 |
| `ms` | 걸린 시간 |

`take` 의 답: `{op: "take", ok, id, at, size, next, end, bytes, crc32, text}`. `next` 가 다음 자리, `end` 가 전체 길이다. `next == end` 면 끝.

## 오류와 할 일

| 오류 (앞부분) | 뜻 · 할 일 |
|---|---|
| `stayPrice is not defined` · `러너의 도우미(stay_helper.js)와 부트(stay_boot.js)를 먼저 올려 주세요` | 페이지가 바뀌어 도우미가 내려갔다. 「준비」 4 의 이동 뒤 |
| `앞 작업(…)이 아직 끝나지 않았습니다` | 앞 작업이 아직 돈다. 10초 뒤 `stayPrice.last()` 로 그 답을 받는다. 이 답은 장부에 적지 않는다 |
| `셀 창이 열려 있습니다 — 사람이 닫은 뒤 다시 부릅니다` · `셀 창을 닫지 못했습니다` | 담당자에게 ERP 화면의 가격 칸 창을 닫아 달라고 한다 |
| `앞 화면(드로어·요청)이 아직 정리되지 않았습니다` · `드로어를 닫지 못했습니다` | 몇 초 기다린다. 읽기 작업이면 다시 부른다. 저장 작업이면 장부에 적고 멈춘다(누르지 않았다) |
| `[가격 캘린더] 탭을 찾지 못했습니다` · `가격 캘린더가 열리지 않았습니다` | 탭이 그 호텔의 Stay 편집 화면이 아니거나 로그인이 풀렸다. 스크린샷으로 보고 「준비」 2·3 |
| `캘린더의 오퍼 칩에서 \`…\` 을 찾지 못했습니다 (보이는 오퍼: …)` · `캘린더에 \`… · …\` 칩이 없습니다 (보이는 칩: …)` · `드로어의 오퍼가 \`…\` 입니다` | 이름이 화면과 다르다. 보이는 이름을 담당자에게 보여 주고 골라 받은 뒤 요청 파일을 고쳐 다시 읽는다. 아무것도 바뀌지 않았다 |
| `\`weekdays\` 는 …` · `\`dates\` 는 이어진 날짜 목록이어야 합니다` · `\`occupancy\` …` · `\`rows\` 가 비었습니다` | 넣은 값이 명령의 값과 다르다. 명령이 낸 값을 그대로 다시 넣는다 |
| `[선택 날짜 가격 수정] 이 기간을 거절했습니다 — …` | ERP 가 그 기간을 받지 않았다(판매일 없는 날이 끼는 등). 뒤의 화면 글을 담당자에게 전한다 |
| `드로어가 …` · `드로어의 날짜(…)가 물은 날짜(…)와 다릅니다` · `가감 확인 단계가 고른 것과 다른 범위를 보여 줍니다` | 화면이 물은 것과 다른 것을 열었다. 읽지도 저장하지도 않았다. 멈추고 보고한다 |
| `이 화면에는 [선택 날짜 가격 가감] 창이 없습니다` | 이 ERP 화면에는 예약 있는 날을 알아낼 창이 없다. 멈추고 보고한다 |
| `드로어 표에 없는 줄이나 칸이 있어 저장하지 않았습니다` · `넣은 값을 다시 읽으니 달라 저장하지 않았습니다` | 누르기 전에 거절했다(`refused`). 저장 안 됨. 장부에 적고 멈춘다 |
| `… 칸을 누를 수 없습니다(판매일이 없거나 이 달에 없는 날)` · `연 셀 창의 날짜(…)가 저장할 날짜(…)와 달라 아무것도 바꾸지 않았습니다` · `연 셀 창이 다른 요금제입니다` · `셀 창에 … 줄이 없어 저장하지 않았습니다` | 셀 창 저장을 누르기 전에 멈췄다. 저장 안 됨. 장부에 적고 멈춘다 |
| `셀 창이 저장을 거절했습니다 — …` | ERP 가 저장을 거절했다. 저장 안 됨. 화면 글을 전하고 멈춘다 |
| `저장 단추는 눌렸고 저장됐는지 알 수 없습니다` · `[저장] 은 눌렸고 저장됐는지 알 수 없습니다` · `저장 단추는 눌렸습니다. 저장됐는지 알 수 없으니 다시 읽어 확인합니다` | `saved: "unknown"`. 다시 부르지 않는다. SKILL.md 「중간에 멈췄을 때」 |
| `시간(…초) 안에 끝나지 않아 멈췄습니다` | 시간 안에 못 끝냈다. `pressed` 가 없으면 저장 안 됨, 있으면 위의 「알 수 없음」 |
| `허용 목록에 없는 클릭을 막았습니다: …` · `허용 목록에 없는 클릭이 있어 멈췄습니다` | 벽이 막았다. 돌아가지 않는다. 막힌 것(`blocked`)을 담당자에게 알리고 멈춘다 |
| `그 조각이 페이지에 없습니다` | 페이지가 바뀌었거나 조각이 40개를 넘어 밀려났다. 새 폴더로 읽기를 다시 한다 |
| `자리(at)는 …` · `크기(size)는 200 부터 800 까지입니다` · `이 크기로는 한 글자도 담지 못합니다` · `이 자리에서 자르면 글자가 바뀝니다` | 같은 자리에서 크기를 바꿔(800 → 600 → 400) 다시 받는다 |
