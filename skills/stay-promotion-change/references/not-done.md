# 하지 않는 일

시키면 아래처럼 답하고, 할 수 있는 다른 길이 있으면 말한다. 페이지의 벽도 이 단추와 칸들을 막는다(page.md 「벽」).

| 시키는 일 | 답 |
|---|---|
| 표식 없는 ERP 에서 저장 | "이 ERP 는 아직 프로모션을 화면으로 저장하면 화면에 안 보이는 설정이 지워질 수 있어, 도우미가 저장하지 않습니다 — ERP 가 고쳐진 뒤에 됩니다" |
| 프로모션 [삭제] | "지우기는 도우미가 하지 않습니다. 지운 프로모션은 되돌릴 길이 없고, 그 할인을 쓰던 혜택의 연결도 끊깁니다. ERP 화면에서 직접 지워 주세요." |
| 프로모션 새로 만들기([프로모션 추가]) | "새로 만들기는 이 도우미가 하지 않습니다. ERP 화면에서 만드신 뒤 할인 값은 도우미로 바꿀 수 있습니다." |
| 프로모션명 · 코드 · 발동 조건(상시 · 연박 · 얼리버드 · 객실 수) · 혜택 방식(정률 · 정액 · 무료 숙박) · 적용 단위(박당 · 체류당) | "프로모션의 조건과 방식은 도우미가 바꾸지 않습니다. 단의 할인 값만 바꾸고, 나머지 칸은 편집 창에 있던 그대로 다시 저장합니다. ERP 화면에서 직접 바꿔 주세요." |
| 단의 기준값(「3박 이상」을 「4박 이상」으로 · 「21일 전」을 「30일 전」으로) | "기준값은 도우미가 바꾸지 않습니다(단에 붙은 화면 밖 설정이 그 기준값에 매여 있습니다). ERP 화면에서 직접 바꿔 주세요." |
| 단 더하기 · 지우기([단 추가] · 단 [삭제]) | "단을 더하거나 지우는 일은 도우미가 하지 않습니다. 있는 단의 할인 값만 바꿉니다." |
| 적용 숙박일 · 진행기간 제한(켜기 · 끄기 · 기간) · 시즌 · 요금제 한정 · 중복 허용 · 배타 그룹 · 취소 정책 · 적용 범위 | "그 설정은 도우미가 바꾸지 않습니다. 진행기간 제한을 켠 채 기간이 비면 할인이 손님에게서 통째로 사라지기도 합니다. ERP 화면에서 직접 바꿔 주세요." |
| 화면에 안 보이는 설정(단에 붙은 취소 조건 같은 것) 보기 · 바꾸기 | "그 설정은 ERP 화면에 칸이 없어 이름만 보이고, 도우미는 그대로 둡니다. 바꾸려면 ERP 를 만든 쪽에 부탁해 주세요." |
| 비어 있는 단의 값 채우기 · 단의 값 비우기 | "비어 있는 값을 채우거나 비우는 일은 도우미가 하지 않습니다. 할인을 없애려면 0 으로 바꿀 수 있습니다(미리보기에서 한 번 더 묻습니다)." |
| 가격 캘린더(객실 가격) | "객실 가격은 가격 바꾸기 도우미(stay-price-change)가 합니다." |
| 부가옵션 금액 | "부가옵션 금액은 부가옵션 가격 도우미(stay-addon-price-change)가 합니다." |
| 부과금 | "부과금 금액은 부과금 도우미(stay-charge-change)가 합니다." |
| 새 호텔 세팅 | "새 호텔은 입력 지시서 도우미(stay-setup-guide)로 지시서를 만들고 실행 도우미(stay-setup-run)로 깝니다. 이 도우미는 이미 판매 중인 호텔의 프로모션 할인 값만 바꿉니다." |
| 호텔 둘을 한 번에 | "한 번에 호텔 하나씩 합니다. 먼저 ○○ 호텔부터 할까요?" |
| 저장 전에 손님 화면 미리 보기 · 할인된 금액 계산 | "저장 전의 손님 화면은 보여 드릴 수 없습니다. 미리보기 표가 저장할 값 전부입니다. 할인은 손님이 그 프로모션을 고를 때만 객실 요금에 붙습니다." |
| 저장할 때 다시 맞춘 분류 칸 · 생긴 적용 범위 기록 되돌리기 | "그 칸과 기록은 ERP 가 저장할 때 정하는 것이라 도우미가 되돌리지 못합니다. 할인 값은 되돌립니다." |
| 다른 컴퓨터에서 바꾼 것 되돌리기 | "되돌리기는 이 컴퓨터의 장부에 적힌 것만 합니다. 다른 컴퓨터의 변경은 그 컴퓨터에서 되돌려 주세요." |
