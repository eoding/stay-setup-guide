# 호텔 화면 사전 — 입력 칸 · 선택지 · 버튼

호텔을 만들고 파는 화면에 **실제로 보이는 글자만** 담았다. 지시서를 쓸 때 이 사전이 정본이다.

- 뽑은 날: 2026-09-03
- 화면 27개 · 입력 칸 201개 · 버튼 60개

**표 읽는 법**

| 표기 | 뜻 |
|---|---|
| 종류 `텍스트`·`숫자`·`여러 줄 글` | 값을 친다 |
| 종류 `선택`·`다중 선택`·`자동완성 검색` | 목록에서 고른다 |
| 종류 `체크박스`·`다중 체크`·`라디오` | 켜고 끈다 |
| 종류 `날짜 고르개`·`시각 고르개` | 달력·목록에서 고르거나 그 형식으로 친다 |
| 종류 `반복 행` | [행 추가]로 줄을 늘려 가며 채운다 |
| 종류 `파일` | 파일을 고른다 |
| 필수 `예` | 비우면 저장되지 않는다 |
| 언제 보임이 빈칸 | 늘 보인다 |

**칸 이름에 `(공급 통화)` 가 붙은 것**은 그 자리에 호텔의 공급 통화 코드가 그대로 찍힌다는 뜻이다. 공급 통화가 USD 인 호텔이면 화면은 `정액 금액 (USD)` · `금액 가치 (USD)` 로 보인다. 지시서에도 그 호텔의 통화를 넣어 같은 형태로 적는다.

**선택지 안의 `〈호텔명〉`** 도 같다 — 그 자리에는 지금 열어 둔 호텔의 이름이 찍힌다.

**편집 화면 탭 순서**: `기본정보` · `호텔 정보` · `객실` · `오퍼` · `시즌` · `요금제` · `판매일` · `가격 캘린더` · `부과금` · `부가옵션` · `프로모션` · `취소정책` · `혜택` · `참조정보` · `추가수집정보` · `환율 설정` · `SEO` · `전용 알림메시지 템플릿`

## 2. 기본정보 탭 (상품 공통 화면)

여는 길: 편집 화면 탭 `기본정보`

> 이 탭은 호텔 전용 화면이 아니라 상품 공통 화면이라 이 사전이 칸을 담지 않는다.
> 지시서가 여기서 쓰는 것은 상품명·영문명·상세설명 글과 대표이미지 올리기다.
> 탭 오른쪽 위 [저장]이 이 탭의 저장이다 — 아래 탭들은 저마다 자기 저장 버튼을 쓴다.

|---|---|---|---|---|---|

## 27. 검증 배너 · 판매 시작

여는 길: 편집 화면 맨 위 검증 배너

| 칸 | 종류 | 필수 | 선택지 / 형식 | 언제 보임 | 거부 문구 |
|---|---|---|---|---|---|
| 사유 | 텍스트 | 예 | 화면 예시 문구: 사유 (예: 이 호텔은 원래 사진을 안 준다) — [이건 넘어가기] 를 누르면 그 줄에만 열린다. 비우면 넘어갈 수 없다. | 노란 항목의 [이건 넘어가기] 를 누른 뒤 |  |

| 배너 문구 | 빨강/노랑 | 넘어갈 수 있나 |
|---|---|---|
| 공급 통화가 지정되지 않았습니다 — 환산·표시가가 계산되지 않습니다 | 차단 | 아니오 |
| 세전(++/nett) 감지 후 세후 변환이 미확정인 가격 셀이 …개 있습니다 | 차단 | 아니오 |

| 오퍼 '…'과 '…'이 같은 날짜를 덮는데 우선순위가 같습니다(…) | 차단 | 아니오 |
| 오퍼 '…'의 판매 구간에 가격 셀이 없습니다 | 차단 | 아니오 |
| 오퍼가 없습니다 — 금액을 계산할 수 없어 판매가 불가능합니다 | 차단 | 아니오 |

| 시즌 '…'이 '…'을 통째로 포함합니다(오퍼 '…', …일) — 좁은 쪽('…', 우선순위 …)이 넓은 쪽(우선순위 …)보다 커야 의도대로 적용됩니다 | 경고 | 예 |
| 오퍼 '…'에 시즌이 없습니다 — 재전개·일괄 편집이 불가합니다 | 경고 | 예 |

| 오퍼 '…'의 표시명이 비어 있어 고객에게 관리용 이름이 노출됩니다 | 경고 | 예 |

버튼: [같은 문제 N건 ▼] [제안값 보기] [세후가로 확정] [다시 보기] [이건 넘어가기] [넘어가기] [판매 시작]

> 배너는 두 묶음이다 — 빨간 묶음 제목은 「🔴 이대로면 못 팝니다 (건수)」, 노란 묶음 제목은 「🟡 채우면 좋음 (건수)」.
> 같은 규칙이 여러 건이면 「같은 문제 N건 ▼」로 접히고, 그 안에서도 넘치면 「외 N건」으로 더 접힌다.
> 빨간 항목이 하나라도 있으면 [판매 시작]을 누를 수 없다.
> 노란 항목은 [이건 넘어가기] → 사유 칸에 적고 [넘어가기] 로 지나갈 수 있다. 사유는 필수다.
> 사유 칸의 예시 문구는 「사유 (예: 이 호텔은 원래 사진을 안 준다)」이고, 넘어간 항목에는 「넘어감」 표가 붙고 [다시 보기] 로 되돌린다.
> 같은 규칙은 호텔당 한 번만 넘어가면 된다.
> 판매 중이면 「판매중」 표와 「오퍼 N건이 고객 화면에 팔리는 중입니다」가, 없으면 「판매 없음」 표와 「판매 중인 오퍼가 없습니다」가 보인다.

## 이 사전이 담지 못하는 것

- 왼쪽 메뉴의 이름과 순서 — 여행사마다 다르게 설정하는 값이라 화면을 열어 봐야 안다.
- 선택지에 실제로 뜨는 목록 — 룸·오퍼·시즌·요금제·취소정책·거래처·캠페인은 그 호텔에 무엇을 만들었는지가 정한다.
- 저절로 채워지는 값 — 상품코드·수수료 네 칸·정렬 기본값은 화면이 채운 뒤에야 보인다.
- 이미 있는 값 때문에 잠기는 칸 — 이미 연결된 룸의 체크박스가 회색으로 잠기는 것 등.
- 달력·시각 고르개가 실제로 펼쳐 보여 주는 목록.
- 저장한 뒤 잠깐 떴다 사라지는 안내 띠와 그 문구.
- 운영 번역이 덮어쓴 글자 — 아래 README 의 한계 참고.
