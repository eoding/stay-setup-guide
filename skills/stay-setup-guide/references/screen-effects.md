# 화면 칸 도움말과 고객 화면 영향

`screen-effects.json`은 제공된 화면 안내 영향 지도의 31개 화면·242개 칸에서 가져온 도움말·고객 표시 위치·효과다. 현재 화면 사전의 `허용 인원 조합(선택)`을 보충해 243개 칸으로 맞췄다. 새 재고 폼은 별도 보충 화면 3개·컨트롤 7개로 담았다. 원본 HTML을 실행하거나 외부 서비스를 조회하지 않는다.

## 찾기

```bash
python3 scripts/explain_field.py '호텔명' --screen '호텔 만들기'
python3 scripts/explain_field.py '예약 마감'
python3 scripts/explain_field.py --screen '연령 구간'
python3 scripts/explain_field.py '총 수량' --json
```

같은 칸이 화면 여럿에 있으면 후보를 전부 보여 준다. 사용자가 말한 화면이나 현재 열린 화면으로 한정하고, 없는 칸의 효과를 지어내지 않는다. 원본의 각 화면 요약은 `summary`, 도움말은 `help`, 고객 표시 위치는 `web`, 동작 영향은 `effect`, 역할은 `downstream`이다.

## 답변과 지시서 작성에 쓰는 법

- “어디에 보이나?”에는 고객 페이지·표시 위치를 먼저 답한다. 글자로 직접 표시되는 칸과 판매 조건으로만 작동하는 칸을 구분한다.
- `게이트`는 고객 화면에 문구가 없더라도 오퍼·객실·가격·할인 노출이나 예약 가능 여부를 바꾼다. 보이지 않는다고 무시하거나 비우지 않는다.
- `미사용`·`내부 전용`은 정산·관리 정보일 수 있다. 고객 페이지에 안 보인다는 이유로 계약서의 값을 바꾸지 않는다.
- `web_not_shown`은 지금 고객 화면에 나오지 않는 항목과 그 이유다. 고객에게 보인다고 안내하지 않는다.
- 원고 작성 때 계약 조건을 어느 화면 칸에 넣을지와 입력 순서를 판단하는 데 쓴다. **산출 지시서에는 이 설명을 복사하지 않는다.** 지시서는 기존 `MANUAL-SPEC.md`대로 화면·칸·값·저장만 적는다.
- 재고는 [inventory-guide.md](inventory-guide.md)의 선택 조건과 실제 폼을 따른다. 수량이 없는 계약에 재고를 기본으로 추가하지 않는다.

## 기준과 한계

기존 242개 칸은 **운영 2026-09-21 화면 기준으로 배포 코드를 읽어 정리**한 것이다. 화면을 띄워 확인한 결과가 아니다. 허용 인원 조합은 2026-09-23, 재고는 운영 2026-10-08 폼과 배포 규칙으로 보충했다. 실제 화면과 다르면 현재 화면을 먼저 따르고 그 차이를 알려 준다.
